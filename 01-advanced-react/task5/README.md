# Задача 5. Карточка через композицию

## Цель

Собрать повторно используемый UI без набора специальных флагов.

## Что нужно сделать

1. Сделайте Panel с title, children и областью actions. Внутри не должно быть бизнес-ветвления по id курса.
2. Используйте Panel для карточки курса и блока фильтра: содержимое передаётся снаружи.
3. Предусмотрите отсутствие actions и длинный заголовок без разрушения структуры.

## Требования к результату

- Оба сценария используют один Panel.
- Кнопки доступны с клавиатуры, пустой actions не оставляет лишний интерактивный элемент.

## Запуск

```bash
cd 01-advanced-react/task5
npm install
npm run dev -- --host 127.0.0.1
```

## Наблюдения

1. Panel

   `Panel` принимает `title`, `children` и необязательный `actions`. Внутри только разметка: `section` с `aria-labelledby` на заголовок (id через `useId`), `h2`, тело и блок для actions. Про курсы, id и места Panel ничего не знает, никаких условий по id внутри нет.

2. Два сценария

   Один и тот же `Panel` используется для блока фильтра и для карточек курсов. У фильтра в `children` select категории, в `actions` кнопка «Сбросить», которая передаётся, только когда категория выбрана. У карточки в `children` категория и места, в `actions` кнопка «Выбрать», если места есть. Всё это решается в `App`, снаружи Panel.

3. Нет actions и длинный заголовок

   Если `actions` не передан, блок `.panel-actions` не рендерится совсем. У «Типизация данных» мест нет, поэтому в карточке нет ни кнопки, ни пустого контейнера, и фокусироваться там не на чем. Для проверки длинного заголовка в данные добавлен курс `a11y` с очень длинным названием, в котором есть слово с подчёркиваниями без пробелов. Заголовок переносится за счёт `overflow-wrap: anywhere`: на ширине 375px горизонтальной прокрутки нет, заголовок не вылезает за карточку, кнопка остаётся внутри.

4. Клавиатура

   Все действия это обычные `button`, поэтому они доступны с клавиатуры. Проверка через Tab: фокус попадает на select, стрелка вниз выбирает frontend, появляется «Сбросить», Tab переходит на неё, Enter сбрасывает фильтр. После сброса кнопка исчезает, поэтому фокус переводится обратно на select, чтобы он не потерялся. Дальше Tab сразу попадает на «Выбрать» первой карточки, а карточку без мест пропускает. Enter выбирает курс, кнопка становится «Выбран» с `aria-pressed="true"`.

Самопроверка: `npm run build` проходит без ошибок.
